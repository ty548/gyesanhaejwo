# 계산해줘 광고 수익 시나리오

작성일: 2026-10-01. 실제 방문·광고 데이터가 없어 아래 숫자는 **예측이 아닌 가정별 민감도 계산**입니다. 페이지 RPM은 1,000 페이지뷰당 광고 수익입니다.

## 계산식

- 월 광고 수익 = 월 페이지뷰 ÷ 1,000 × 페이지 RPM
- 월 순수익 = 월 광고 수익 − 월 총비용
- 월 비용 대비 수익률(ROI) = 월 순수익 ÷ 월 총비용 × 100
- 손익분기 페이지뷰 = 월 총비용 ÷ 페이지 RPM × 1,000

## 예시 입력과 결과

월 총비용은 **30,000원**으로 가정합니다. 이는 Vercel Pro 기본 요금, 환율·부가세와 도메인·추가 사용량 등의 변동 가능성을 감안한 모델 입력값이며 실제 청구액이 아닙니다. 페이지 RPM **500원 / 1,500원 / 3,000원**도 관측치나 보장 수익이 아닌 시뮬레이션 입력값입니다.

| 시나리오 | 월 페이지뷰 | 가정한 페이지 RPM | 월 광고 수익 | 월 순수익 | 월 비용 대비 ROI |
| --- | ---: | ---: | ---: | ---: | ---: |
| 보수 | 10,000 | 500원 | 5,000원 | -25,000원 | -83.3% |
| 기준 | 50,000 | 1,500원 | 75,000원 | 45,000원 | 150% |
| 상향 | 100,000 | 3,000원 | 300,000원 | 270,000원 | 900% |

월 비용 30,000원, 페이지 RPM 1,500원이라면 **월 20,000 페이지뷰**가 단순 손익분기점입니다. 초기 제작비·콘텐츠 제작비·광고 집행비·세금은 이 표에 포함하지 않았습니다. 월 방문자 수가 아닌 **페이지뷰**를 입력해야 합니다.

## 실제 수치로 갱신할 때

1. 배포 후 30일간 분석 도구에서 사람 방문자의 페이지뷰를 확인합니다.
2. 광고 승인 이후 AdSense 보고서에서 실제 페이지 RPM을 확인합니다.
3. Vercel·도메인·마케팅·콘텐츠 제작 비용을 월 비용에 합산합니다.
4. 위 계산식으로 순수익과 ROI를 다시 계산합니다.

광고 배치는 계산기 입력과 결과를 가리지 않도록 결과 아래와 계산 설명 아래에서 검토하는 것이 좋습니다. 광고 승인은 보장되지 않으며, 방문자 클릭을 유도하거나 계산 버튼에 광고를 너무 가깝게 두지 않아야 합니다.
