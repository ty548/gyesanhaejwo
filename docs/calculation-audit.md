# 계산 로직 검증 기록 (2026-10-01)

이 사이트의 결과는 입력값을 이용한 추정치입니다. 은행 심사, 급여명세서, 세무 신고서와 동일한 결과를 보장하지 않습니다.

| 계산기 | 확인한 계산 방식 | 남은 범위 제한 |
| --- | --- | --- |
| 대출 | 원리금균등 월 상환액과 원금균등 월별 이자 합계. 정수 연수·개월수만 허용 | 거치기간, 중도상환, 변동금리 없음 |
| 퇴직금 | 퇴직일 전 3개월 달력 일수와 근속일수 사용. 평균임금보다 입력한 통상임금이 크면 통상임금 적용 | 육아휴직 등 평균임금 산정 제외기간, 연차수당 자동 계산, 퇴직소득세 없음 |
| 연봉 실수령액 | 2026년 근로자 부담 국민연금 4.75%, 건강보험 3.595%, 장기요양 0.4724%, 고용보험 0.9%. 국민연금 기준소득월액 41만~659만원 | 소득세는 사용자가 월 원천징수액 입력. 가입 제외, 보험료 절사 및 보수월액 신고 차이 없음 |
| 시급·주휴수당 | 주 15시간 이상·개근 시 주휴시간을 주 근로시간의 1/5로 계산. 주 40시간 기준 월 209시간 | 연장·야간·휴일 가산수당, 불규칙 일정 없음 |
| 적금·예금 | 예금은 단리, 적금은 월초 납입 단리 합계. 입력 이자 과세율 반영 | 일할 이자, 우대금리, 복리, 중도해지 없음 |
| 부가세 | 일반과세자 10%, 매출세액에서 공제 가능 매입세액 차감. 음수면 환급 가능액 분리 | 간이과세, 면세·영세율, 공제 불가 세액 및 신고 조정 없음 |
| DSR·LTV | 신규 대출 원리금균등 12개월 상환액과 입력한 기존 연 상환액으로 DSR. 대출금/주택가치로 LTV | 스트레스 금리, 대출 종류별 법정 산식과 실제 규제 한도 없음 |
| 아파트 구매 | 매매가에 직접 입력한 취득세율·중개보수 VAT·법무·등기·이사·수리·대출 부대비를 더하고 대출금을 차감. 상환방식별 첫 달·1년차·전체 이자 계산 | 세율·상한 자동 판정, 보유세 없음 |
| 상가 취득·수익률 | NOI=연 임대수입-공실 손실-운영비. Cap Rate=NOI/매매가, CoC=세전 현금흐름/자기자본, DSCR=NOI/1년차 부채상환액 | 임차보증금 반환, 건물분 부가세, 소득세, 매각 손익 없음 |
| 환율 | 18개 통화의 Frankfurter 기준 환율 또는 직접 입력 환율로 환산. 입력 수수료율과 우대율 비교 | 은행 현찰 매매율·스프레드, 환율 시차 없음 |
| 날짜 차이·N일 전후·D-Day | 로컬 오늘 날짜를 YYYY-MM-DD로 만든 뒤 UTC 캘린더 날짜로 계산 | 시간대별 시각 차이 없음 |
| 영업일 | 시작일 포함 선택에 따라 기간을 세고 토·일요일 제외 | 법정공휴일 자동 제외 없음 |
| 근무시간·영상 배속 | 자정 넘어가는 퇴근 처리. 원본 영상 길이/배속으로 시청시간 추정 | 실제 휴식·중단시간 없음 |
| 퇴근시계·월급시계 | 브라우저 시각으로 근무 진행률·시간 비례 수입 추정 | 휴게시각은 균등 배분하며 세금·수당 자동 계산 없음 |
