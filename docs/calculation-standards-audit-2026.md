# 계산해줘 계산 기준 감사 2026

## 감사일

2026-10-02. 코드 기준점: `bece660baf3937a26b056b7a1f3db58480c1e4a3`. 대상은 `src/catalog.js`와 빌드된 사이트맵의 계산기 19개다. 홈을 포함한 페이지는 20개다.

## 전체 요약

- 코드 실행 일치와 제도상 정확성을 별개로 판정했다. 19개 계산기 각각에 독립 참조값 2개와 경계값 1개를 `test/independent-vectors.test.js`에서 비교했다. 고용노동부 퇴직금 예제와 2026년 최저임금 월 환산 예제도 별도로 비교했다.
- 공식 원문에서 확인한 2026년 값은 국민연금 근로자 부담 4.75%, 기준소득월액 41만~659만 원(2026-07-01부터), 건강보험 근로자 부담 3.595%, 장기요양 근로자 부담 보수월액 대비 0.4724%, 고용보험 근로자 부담 0.9%, 최저임금 10,320원이다. 소득세는 자동 산정하지 않고 직접 입력한다.
- DSR·LTV와 취득 관련 세금·중개보수는 거래 조건에 따라 달라진다. 화면의 입력 기본값은 **비교용 예시**이며 법정 공통 한도가 아니다. 자동 규제·세액 판정 엔진으로 확장하지 않았다.
- 환율 API의 네트워크, 서버, 미지원 통화, 유효하지 않은 환율, 조회 불가 통화쌍을 구별했다. 직접 입력 경로는 유지했다.
- 공식 원문을 열어 확인한 주요 URL은 아래 목록에 기록했다. 검색 결과 요약만으로 값을 바꾸지 않았다.

### 산식·기간·절사 확인

- 퇴직금은 마지막 근무일 다음 날을 퇴직일로 사용하고, 사유 발생 전 3개월의 달력 일수로 평균임금을 구한다. 고용노동부 예제의 `7,080,000 + 1,000,000 + 75,000`원을 92일로 나눈 1일 평균임금과 1,080일 재직 결과를 독립 비교했다. 상여·연차수당의 3개월 가산분은 사용자가 직접 입력한다. 평균임금 산정 제외기간과 IRP·퇴직소득세는 자동 반영하지 않는다.
- 급여의 건강·장기요양 보험료는 확인된 비율을 보수월액에 곱해 추정한다. **실제 보험료의 기준소득월액 신고, 천 원 미만 절사, 원 단위 처리, 상·하한·감면은 개별 고지액과 달라질 수 있다.** 급여의 소득세는 간이세액표를 자동 적용하지 않고 입력받는다. 부양가족 정보도 입력받지 않는다.
- 시급 계산의 주휴시간 자동 기본은 `주 소정근로시간 ÷ 5`다. 고용노동부는 정상 근로일의 소정근로시간이 다를 수 있음을 예시로 설명한다. 따라서 불균등 근무용 주휴 유급시간 입력을 추가했다. 2026년 주 40시간·209시간 공식 예제의 월 2,156,880원을 비교했다.
- 적금은 월초 납입 단리, 예금은 월 단위 단리다. 은행의 실제 일수 계산과 원 단위 절사 방식은 상품마다 다르다. 비과세·세금우대는 자동 적용하지 않는다.
- VAT는 일반과세자의 `매출세액 − 공제 가능한 매입세액` 방향을 표시한다. 면세·영세율·공제 불가 매입세액, 각종 공제와 신고·환급 시기는 반영하지 않는다.
- DSR은 입력 금리로 계산한 신규 대출 원리금균등 월 납입액 × 12에 기존 연간 원리금을 더하는 단순 모형이다. 스트레스 DSR, 차주별 적용, 정책대출 예외가 없다. LTV의 분모는 사용자가 입력한 주택 가치다.
- 아파트와 상가의 합산 취득세율·중개보수율은 직접 수정할 수 있다. 주택 수, 가격 구간, 면적, 생애최초 감면, 법인, 증여·상속, 지방교육세, 농어촌특별세, 채권 할인율을 자동 판정하지 않는다. 2026년 지방세제 **개편안**은 현행 시행 규정으로 취급하지 않았다.
- 환율은 Frankfurter `/v2/rate/{from}/{to}`가 제공하는 통화 1단위당 상대 통화 단위를 사용한다. JPY·VND를 100단위로 바꾸지 않는다. 응답 날짜를 표시하며, 은행 고시환율과 수수료·스프레드는 별개다. 실제 통화쌍 제공 여부는 API 응답에 따른다.
- 날짜 계산은 UTC 자정의 달력 일수 차이를 사용하므로 윤년·월말·DST에서 1일 밀림이 없도록 검증했다. 영업일은 현재 토·일요일만 제외한다. 퇴근·월급시계는 브라우저 로컬 시각과 저장된 입력값을 사용하며, 자정을 넘는 야간근무의 퇴근 후 상태를 회귀 검증했다.

- 퇴직금 산정 제외기간, 상여·연차수당 가산 범위, 1일 통상임금, 계속근로일수의 특수 사례, 퇴직소득세 및 IRP.
- 불균등 근무의 정상 근로일·주휴 유급시간, 실제 개근·유급휴일 여부.
- 대출기관별 일수 계산, 원 단위 절사, 변동금리·거치기간·조기상환수수료. 현재 대출 계산기는 거치·조기상환을 지원하지 않는다.
- DSR·LTV의 대출 종류, 차주, 지역, 보유주택 수, 정책대출, 스트레스 금리 및 금융기관 심사 결과.
- 취득세·지방교육세·농어촌특별세·중개보수, VAT 과세대상, 채권·인지·법무비의 거래별 실제 금액.
- 환율 API의 실시간 가용성, 통화쌍 제공 여부, 환율 제공기관별 시각과 은행 실제 거래환율.
