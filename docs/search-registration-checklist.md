- [ ] `https://gyesanhaejwo.vercel.app/`을 URL 접두어 속성으로 추가하고 소유권을 확인한다. 사용자 계정에 이미 등록되어 있다면 해당 속성을 선택한다.
- [ ] `https://gyesanhaejwo.vercel.app/sitemap.xml`을 Sitemaps 메뉴에 제출한다.
- [ ] URL 검사에서 홈 `https://gyesanhaejwo.vercel.app/`과 일반 계산기 `https://gyesanhaejwo.vercel.app/calculator/`의 라이브 URL을 검사한다.
- [ ] 검사 결과가 색인 가능하면 필요에 따라 색인 생성 요청을 한다. 이후 페이지 색인 보고서로 실제 처리 상태를 확인한다.
